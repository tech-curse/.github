# Política de segurança

## Versões suportadas

Só a versão mais recente de cada repositório recebe correções de segurança. Não há manutenção de versões antigas.

## Como reportar uma vulnerabilidade

**Não abra uma issue pública.** Use o reporte privado do GitHub:

1. Abra a aba **Security** do repositório afetado.
2. Clique em **Report a vulnerability**.
3. Descreva o problema, como reproduzi-lo e o impacto que você enxerga.

O reporte fica visível só para os mantenedores até a correção ser publicada.

## O que esperar

Este é um projeto pessoal, mantido no tempo livre:

- confirmação do recebimento em até 7 dias;
- avaliação e, se o problema for confirmado, um plano de correção logo em seguida;
- crédito a quem reportou no aviso de segurança, se a pessoa quiser.

## Escopo

Entram no escopo o código dos repositórios públicos da organização e as imagens de contêiner publicadas por eles. Não entram testes de carga, negação de serviço nem engenharia social.
