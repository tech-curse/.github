# .github

Arquivos de comunidade padrão da organização **tech-curse**. O GitHub aplica cada arquivo daqui a todo repositório da organização que não tiver o seu próprio:

- templates de issue e de pull request;
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md` e `SECURITY.md`.

O README exibido na página da organização fica em [`profile/README.md`](profile/README.md).
